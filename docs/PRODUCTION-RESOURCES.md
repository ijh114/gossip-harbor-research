# 신규 게임 제작 리소스 계획

사용자가 선택한 범위는 **MVP부터 출시형 패스·앨범·대표 이벤트까지**다. 원작의 누적 업데이트 자산 수를 신규 게임의 발주 수량으로 삼지 않는다. 각 체인의 단계 수, 앨범 장수, 시즌 수, 이벤트 종류 수, 출력 해상도는 편집 가능한 초안이며 최종 승인을 받은 제작 사양이 아니다.

웹의 [제작 리소스](https://gossip-harbor-research.pages.dev/#production-assets)에서 원작 관측과 새 게임 제작 초안을 나란히 보고 범위를 결정한다.

## 범위와 조작

| 범위 | 선택 항목 | 포함하는 내용 |
|---|---:|---|
| MVP | 27 | 기본 보드·아이템/생성기·주문·첫 맵·캐릭터·기본 상점·UI·연출·오디오·납품 기준 |
| 출시형, 기본 선택 | 40 | MVP와 추가 체인·상황형 BM·패스·앨범·대표 이벤트 |
| 장기 확장 포함 | 43 | 다음 챕터·테마 확장·추가 미니게임 |

항목별 포함 여부, 수량, 작업/출력 규격, 추가 요청과 프로젝트 공통 요청을 수정할 수 있다. 범위 전환은 체크 상태를 바꾸고 수량·규격·사용자 메모는 보존한다. 카테고리와 검색은 표시만 바꾼다. 요청 수량은 0–10,000 정수이며 잘못된 수량이 남은 선택 항목은 요청서 내보내기를 막고 해당 입력으로 이동한다.

저장은 현재 브라우저의 localStorage에 한정된다. Markdown 요청서, UTF-8 BOM CSV 작업 목록, 상세 JSON을 내려받아 담당자에게 전달한다. 다른 호스트와 브라우저가 초안을 자동 동기화하지 않는다. JSON은 상세 발주 자료이며 현재 페이지의 가져오기 형식으로 제공하지 않는다.

## 수량과 원작 관측의 경계

- 43개는 발주 목록의 항목 수다. 그림 수나 작업 인일이 아니다. 아이콘·일러스트·화면 세트·모션·VFX·SFX·곡 등은 단위별로 합산한다.
- 동봉 번들 245개, 직렬화 Unity 객체 110,632개 중 Sprite 1,820·Texture2D 2,608·AnimationClip 261·AnimatorController 153·ParticleSystem 6,335·AudioClip 164는 정적 객체 수다. 중복 제거한 완성 이미지/효과/곡 전체 수가 아니다.
- 기본 552타입 중 544타입에 이미지가 연결된다. 고유 Sprite 객체 527개와 고유 PNG 522개는 서로 다른 집계다. 나머지 8개 타입의 미확보 사유는 기존 도감에 남긴다.
- 522개 기본 PNG의 트림된 크기 범위는 가로 67–189px, 세로 67–192px다. 원화 작업 크기나 실제 화면 크기로 사용하지 않는다. 정적 CanvasScaler 기준은 1080×1920이다.
- 페이지에서 실제 이미지 9개의 PNG/rect/pivot/border와 정적 클립 5개의 선언을 비교할 수 있다. 클립 선언 시간과 실제 플레이 연출 시간은 다르다.

공개 데이터는 `src/data/production-assets.json`이며 행마다 관측 근거 유형, 경로·해시·행, 미확인 사항, 선행 항목과 요청 규격을 보존한다. 원본 번들·전체 추출 소스는 게시하지 않는다.

## 그래픽 요청 전에 정할 것

1. 체인 수와 단계, 생성기 수, 첫 맵 구역과 장식 교체 수를 결정한다.
2. 패스 시즌·앨범 장수·대표 이벤트 종류와 테마별 재사용 범위를 정한다.
3. 배경·캐릭터·아이콘·UI·VFX·애니메이션·SFX/BGM의 담당자와 검수자를 정한다.
4. 레이어 원본, 투명 여백·피벗·9-slice, 이름 규칙, 프레임/루프/종료 상태, 압축과 메모리 예산을 Unity 화면에서 확인한다.

제공 영상의 시간순 장면은 [영상 전 구간 검토](https://gossip-harbor-research.pages.dev/#media-audit)에서 확인한다. 맵 장식의 전후 상태뿐 아니라 카메라 이동·HUD 숨김/복귀·대화·선택창·보상 비행, 이벤트 로딩·전용 보드·결과창이 제작 판단 근거다. 표본 사이의 짧은 동작, 정확한 프레임 길이와 오디오 정밀 청취는 별도 검토 대상이다.
