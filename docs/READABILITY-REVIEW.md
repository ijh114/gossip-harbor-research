# 위키 가독성 점검과 수정

대상: 기존 main `904d369` 이후의 웹 위키 전체. 요청 스킬: Impeccable 4.7.1, UI/UX Pro Max. 사용자 요청에 따라 기존 녹색 노트북의 정보 구조와 가독성을 개선했다. 분석 데이터 173건, 상품 선언 251건, 10개 시스템 페이지와 실험 규칙을 보존했다.

## 확인한 문제와 조치

| 우선순위 | 기존 구현에서 확인한 문제 | 반영한 조치 |
|---|---|---|
| P1 | 버튼·표·보조 설명에 8–12px 글씨가 반복됨 | 본문 17px, UI 14–15px, 메타 12–13px로 역할 구분. 한글 Pretendard 가변 폰트 자체 호스팅, 19px 읽기 설정 제공 |
| P1 | 연한 녹색 글자와 연한 바탕의 조합 | 본문/보조 글자색과 의미별 배지의 대비를 재설정. 대표 색상 쌍을 4.5:1 이상으로 검증 |
| P1 | 긴 분석이 2열 카드로 나란히 펼쳐져 읽는 순서가 불명확 | 한 열로 전환하고 요약은 노출, 분석 상세와 미확인 사항은 분리된 disclosure로 구성 |
| P2 | 긴 페이지에서 현재 위치와 원하는 항목을 찾기 어려움 | 페이지별 목차, 현재 구간 표시, 모바일 접이식 목차, 맨 위로 이동, 상세 전체 펼치기 |
| P2 | 검색이 일부 페이지의 필터로만 작동하고 개요에서 갑자기 이동 | 페이지·규칙/원문·상품을 묶은 검색 결과, 항목 바로 이동, 결과 없음과 닫기, 키보드 진입 제공 |
| P2 | 특정 근거를 공유해도 대상 위치로 바로 진입하기 어려움 | `?finding=ID` 링크와 자동 펼치기, 상품 `?product=ID`, 클립보드 복사 제공 |
| P2 | 작은 조작 영역, 표의 키보드 접근, 과도한 페이지 변경 알림 | 주요 컨트롤 44px, 표 영역 키보드 스크롤, 검색 결과 상태 알림, 경로 이동 시 본문/항목 포커스 |

## 스킬 적용 판단

Impeccable의 Read/Operate 원칙에 따라 기존 브랜드를 유지하면서 서체·간격·읽기 순서·상태를 정리했다. 컨텍스트 명령은 한 번 호출했으나 출력이 전달되지 않아 기존 구현과 AGENTS.md를 직접 읽었다. PRODUCT.md와 DESIGN.md는 기존에 없었다. 새 시각 콘셉트 선택이나 브랜드 교체는 수행하지 않았다.

UI/UX Pro Max의 문서형 검색/계층 권장사항은 적합했다. 최초 추천의 영문 세리프 조합은 한국어 위키에 부적합하여 적용하지 않았다. `Korean sans interface` 조회의 단일 한글 산세리프·굵기 계층 원칙을 채택했고, 실제 서체는 기존 성격과 잘 맞는 Pretendard로 결정했다. 라이선스 및 배포 원본: [Pretendard 공식 저장소](https://github.com/orioncactus/pretendard/tree/v1.3.9). 검증하지 않은 추천 결과를 MASTER 파일로 저장하지 않았다.

## 검증

- Node 검사 16개: 10개 페이지 이동, 근거 창, 공유 링크 복사/진입, 상세 펼치기, 글씨 설정 저장, 목차 이동, 전체 검색과 상품 필터, 보드 선택/합성/충전, 맵 day 선택, 모바일 메뉴 포커스/닫기.
- 대표 텍스트/바탕 쌍의 대비 검사, 폰트 파일 유효성, 빌드 및 게시 경로/원본 아티팩트 제외 검사.
- Impeccable 소스 검사 `type`, `layout`: 수정 후 보고된 항목 없음. 이 결과는 실제 브라우저의 모든 상태를 검증한 점수가 아니다.
- 브라우저 도구가 `Local browser use is disabled in Work settings`를 반환했다. 현재 사이트의 최신 스크린샷 fixture도 없으므로 실제 렌더링 화면 검사와 터치/확대 조작 검증은 수행하지 못했다. DOM 검사와 소스의 반응형 규칙으로 확인한 범위만 보고한다.
- 후속 화면 검증 대상: 375/768/1024/1440px, 200% 확대, 긴 제목/원문, 검색창과 근거 창, reduced-motion, 목차와 고정 헤더 간격. 확인되지 않은 항목을 접근성 준수 또는 시각 검수 완료로 표시하지 않는다.
