## 원작과의 일치 여부 및 후속 범위

위 완료는 1–14번의 출처 기반 웹 구현·감사·자료화를 뜻한다. 원작 계정에서의 실행 검증이나 현행 서버의 가격·노출·A/B 실험 확인을 뜻하지 않는다. 전체 튜토리얼 115ID 중 16개는 웹 조건부 논리로 실행하고, 시작 진입 2개는 원작 연출 없이 논리 진입만 처리한다. 나머지 97개는 서버 활동·원작 장면 등 필요한 근거를 지원표에 명시했다. 모두 원작처럼 실행한다고 표시하지 않는다.

실제 집 전체 장면·음향·제공 영상 전체 검토·Unity 게임 구성은 15번 이후의 후속 범위다. 기본 맵/과제 성장 연결과 원작 장면의 완전 재현을 구분한다. 서버만 보유한 값은 임의 생성하여 확정하지 않는다.
