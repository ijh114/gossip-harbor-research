# 퍼즐 도감·상호작용 구성

2026-10-29 변경. 기존 `#puzzle`은 타입 도감으로 유지하고 `#puzzle-motion`에 연출 도감을 분리했다. 퍼즐의 네 페이지는 왼쪽 탐색에서 이동하며 중복 상단 탭을 표시하지 않는다. UI와 게임 시뮬레이션의 탭은 각 기능에 유지한다.

- `#puzzle`: 타입·변형 검색, 합성 체인·역할 필터, 원본 이미지 도감.
- `#puzzle-motion`: 실제 동작 영상과 생성·합성·보상·기믹 연출 시연.
- `#puzzle-interaction`: 선택, 이동, 합성, 입력 제한, 만능 젬, 가위, 모래시계, 위치 교환, 드래그 앤 드롭, 합성 힌트, 거미줄 해제, 상자 단계 해제의 12개 GIF 카드.
- `#puzzle-difficulty`: 합성 깊이·시간·공간 압력 비교.

## 자료 구분

합성 GIF 한 개는 기존에 검수한 실제 발췌 영상에서 보드 영역만 다시 잘랐다. 원본 구간 0.3–3.7초, 출력 560×400, 12fps 반복이며 계정/OS 영역은 포함하지 않는다. 원본 앱 버전과 촬영일은 미확인으로 보존한다.

나머지 11개는 사용자가 허용한 APK 규칙 재현이다. 실제 Sprite를 사용하고 순수 모델로 입력 전후 상태를 검증했다. 합성 힌트는 FX-009 근거의 적격 쌍 강조를 설명하는 시연이며 모델 입력 실행이나 실기 측정으로 표시하지 않는다. 배치·포인터·확인 안내·반복 간격·시각 효과는 설명용이다. 실제 사용 영상을 확보한 것으로 표시하지 않는다.

상자 해제는 상자→거미줄 전이이며 완전 해제가 아니다. 거미줄 해제와 별도 카드로 제공한다. 교환은 서로 다른 보드 아이템의 위치 교환이다. 도구 사용은 대상·빈칸 검사와 확인 이후의 소비/결과를 구분한다.

각 GIF의 SHA-256, 정지 이미지, 원본 출처 또는 재현 설정·모델·Sprite 해시는 `src/data/media.json`의 `interaction:*`에 기록한다. 생성기는 비공개 작업 폴더 `analysis/scripts/build_interaction_states.mjs`, `build_interaction_gifs.py`이며 원본 게임 파일을 사이트에 게시하지 않는다.

## 재생 및 검수

초기에는 화면에 보이는 카드만 자동 재생한다. 전체 일시정지, 확대 재생, 근거 보기를 제공한다. 화면 밖·숨겨진 탭·페이지 이탈 시 GIF를 정지 이미지로 바꿔 디코딩을 중단한다. 움직임 줄이기 설정에서는 정지 상태로 시작하며 사용자가 명시적으로 재생할 수 있다. GIF 로딩 실패 시 정지 이미지와 안내를 표시한다.

자동 검사 244개, 빌드 및 게시 경계 검사를 통과했다. Chrome의 1440px 3열과 375px 1열 배치를 확인했다. 모바일 가로 넘침 없음, 기본 버튼 높이 44px, 확대창 폭 343px·이미지 약295px, 키보드 재생/일시정지, 모든 페이지의 상단 탭 제거, 페이지 분리, 확대창 초점과 닫기, 화면 밖 정지, 콘솔 경고/오류 0건을 확인했다. OS 움직임 줄이기 전환과 숨겨진 탭 경로는 DOM 단위 검사로 검증했다.
