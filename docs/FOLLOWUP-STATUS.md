# REA 후속 작업 · 2026-10-28

사용자가 원본·정리 미디어를 공유하여 기존 영상 보류를 해제했다. 이후 검은 화면이 지속되어 **LDPlayer 분석은 중단**하도록 지시했다. 과거 캡처 관측을 APK4.10.5 정적 규칙·실기 검증과 구분한다.

## 완료한 후속 범위

- BM 신규 결론 17개: 부스트 생성 비용, 별도 ChainEnergy 충전창, 노출 횟수와 쿨다운, 신규 번들 생성/기존 상품 노출의 분리, 로그인 설정·캐시·MD5·variant/cohort 표식·가격 출처. 파일 SHA-256과 소스 위치를 보존했다.
- APK 자료 신규 결론 5개: 동봉245번들 실제 객체, Type106→GroceryBag06 참조, CanvasScaler1080×1920, UI 프리팹11종·RectTransform 원시 좌표, controller14개/clip26개.
- 정적195건에 과거 캡처 관측9건·실행 환경 확인1건을 더하여 **205건**이다. 파생 정적 결과와 캡처에 가상의 REA Evidence ID를 부여하지 않았다.
- 새 BM 관측은 보석20/40과 무료 보상 체인, 에너지 도전의 목표/유료 수령권, 보상탑 단계 가격, 테마 가격 변형, 레벨 보상 후 제한 상품, 신규 카드 설명문, 저에너지 후 충전창, 카드팩 피버, ×8/할인 버블이다. 보석80 이후 규칙·서버 자동노출 게이트를 관측으로 확정하지 않았다.
- 공유 카탈로그의 고유453개(이미지340·영상113)를 참조한다. 기존 정리는 이미지 전수·영상 각9개 분산 프레임 관측이며95.08분 전체 연속 재생·오디오 검토를 뜻하지 않는다. 타게임6개를 가십하버 근거에서 제외했다.
- `#captures`와 퍼즐/UI에 선별 이미지·짧은 무음 영상을 연결했다. 원본 하드링크를 수정하지 않고 공개 파생본에서 상단 계정 식별 워터마크·OS 알림 구간을 제외했다.
- 공개 자료는 이미지17개·무음MP4 3개이며25개 선정 원본의 실제 SHA-256을 다시 대조했다. MP4는 원속도·H.264·24fps·약7.58/12/10초다. 정확한 연출 시간 측정을 뜻하지 않는다.
- 원본 Sprite PNG24개와 기본 ItemModelConfig 타입20개 연결을 유지한다. 같은 PNG가 자산·타입 키에 중복 참조되므로44키가 고유 이미지44장을 뜻하지 않는다.
- 후속 BM 조건 실험 페이지에서 서버 원문 키와 분→초 변환, 일별 생성 횟수, 무료 충전/기존 번들/부스트 비용/ChainEnergy 게이트를 조작할 수 있다. 기본 입력은 모두 가정이다.
- Unity용 독립 C# UPM 규칙 패키지와 NUnit 테스트를 작성했다. C# Runtime 실제 컴파일 및 JS fixture 2,701개 비교를 통과했다. Unity Editor/씬 테스트는 아직 실행하지 않았다.

사용자가 알려준 SDK의 ADB37.0.1로 기존 LDPlayer-2의 versionName4.10.5 / versionCode311·Google Play 설치 출처를 확인했다. ABI는 arm64-v8a이며 제공 XAPK의 armeabi-v7a split과 바이트/서명 동일성을 확인하지 않았다. REA 기록은 `ev_40d150cfa0399c88b8a210e5edfd87976591642f9782d347bd03dd25243bc928`이다. 시작 연출 뒤 검은 화면을 관측했으며 원인은 미확정이다. 사용자 요청 이후 추가 LDPlayer 분석을 하지 않는다. 기존 앱 재설치·초기화·실제 광고·결제는 하지 않았다. 별도 검증용 인스턴스는 생성했으나 제공 APK를 추가 설치하지 않았다.

웹 기능·출처·파생본 해시 검사31개와 빌드·게시 경계 검사를 통과했다. 브라우저 연결은 두 차례 닫힌 연결 오류를 반환하여 실제 렌더링·터치·브라우저 영상 디코딩 검수는 수행하지 못했다. DOM 검사·MP4 인코딩/표본 프레임 검토를 실제 브라우저 검수로 표현하지 않는다. 기존 APK 증거를 재사용했으며 중복 바이너리 세션을 열지 않았다.
