# REA 후속 작업 · 2026-10-28

사용자는 남은 작업을 순차 진행하도록 요청한 뒤 **다운로드 중인 영상의 확인·분석은 보류**하도록 명시했다. 영상 관련 프로세스를 중단했고 생성된 중간 결과를 열어보거나 웹 자료로 사용하지 않는다. 아래 진척은 모두 영상과 분리한 APK 정적 자료 및 독립 규칙 코드에서 얻었다.

## 완료한 후속 범위

- BM 신규 결론 17개: 부스트 생성 비용, 별도 ChainEnergy 충전창, 노출 횟수와 쿨다운, 신규 번들 생성/기존 상품 노출의 분리, 로그인 설정·캐시·MD5·variant/cohort 표식·가격 출처. 파일 SHA-256과 소스 위치를 보존했다.
- APK 자료 신규 결론 5개: 동봉245번들 실제 객체, Type106→GroceryBag06 참조, CanvasScaler1080×1920, UI 프리팹11종·RectTransform 원시 좌표, controller14개/clip26개.
- 조사 항목은 기존173 + 신규22 = **195건**이다. 파생 정적 결과에 가상의 REA Evidence ID를 부여하지 않았다.
- 원본 Sprite PNG24개만 갤러리에 연결했다. 기본 ItemModelConfig 타입20개와 명시적 Image 키로 연결했다. 같은 PNG가 자산·타입 키에 중복 참조되므로 미디어 키44개가 고유 이미지44장을 뜻하지 않는다.
- 후속 BM 조건 실험 페이지에서 서버 원문 키와 분→초 변환, 일별 생성 횟수, 무료 충전/기존 번들/부스트 비용/ChainEnergy 게이트를 조작할 수 있다. 기본 입력은 모두 가정이다.
- Unity용 독립 C# UPM 규칙 패키지와 NUnit 테스트를 작성했다. C# Runtime 실제 컴파일 및 JS fixture 2,701개 비교를 통과했다. Unity Editor/씬 테스트는 아직 실행하지 않았다.

## 다음 근거가 필요한 범위

| 항목 | 현재 상태 | 필요한 것 |
|---|---|---|
| 실제 BM 등장 시점·빈도 | 조건부 정적 분석 보강 | 해당 계정의 설정·시각·재화와 실행 기록 |
| 현행 상품·이벤트·A/B 배정 | 서버 소비 경로 확인 | 실제 config·SDK 가격·계정 배정. 서버 배정 공식은 클라이언트에서 복원 불가 |
| 영상·스크린샷 | 사용자 요청 보류 | 사용자의 재개 지시 전까지 접근하지 않음 |
| 원작 UI·연출 재생 | 실제 프리팹/클립 선언 확보 | 활성 레이아웃·속도·전이·프레임 관측 |
| 광고·결제 | 정적 경로만 확인 | 통제된 관측 자료. 실제 결제는 수행하지 않음 |
| 원작 경제·매출 효과 | 로컬 조건/기본값 확보 | 선택 variant·주문/생성 시계열·전환/매출 자료 |
| Unity 완성 게임 | 독립 규칙 코드 포팅·대조 완료 | Editor import/테스트, 씬·새 아트·연출·콘텐츠·플랫폼 빌드 |

REA MCP는 정상 연결되어 있고 열린 바이너리 세션은 없다. REA의 기본 adb 경로는 미지정이나 기존 Unity SDK의 adb로 읽기 조회한 결과 연결 기기가 없었다. 새 에뮬레이터 설치나 기기 변경은 수행하지 않았다. 브라우저 화면 검수는 기존 로컬 브라우저 접근 제한으로 남아 있으며 소스/DOM 검증과 구분한다.

웹 기능/데이터/원본 PNG 무결성 검사27개, 빌드·게시 경계 검사를 통과했다. 현재 REA 서버의 연결과 기존 증거를 재사용했으며 APK를 중복 분석 세션으로 다시 열지 않았다.
