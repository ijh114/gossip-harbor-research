## 게시 방식과 검증 기준

`main`을 푸시하면 GitHub Pages는 자동 검사→정적 빌드→게시 워크플로를 실행하고, Cloudflare는 기존 Git 연동에서 같은 `dist`를 게시한다. 별도 토큰 방식 Cloudflare 워크플로는 활성화하지 않는다. 상대 경로와 해시 탐색을 유지하여 GitHub 프로젝트 하위 경로를 지원한다.

배포 후 두 호스트의 설정 revision, 새 데이터와 대표 모듈·이미지·영상 응답을 로컬 빌드와 대조하고 실제 연구/플레이/BM 화면을 확인한다. 이 문서의 로컬 검사 결과와 외부 서비스의 게시 성공 여부를 구분한다.

## 확정하지 않은 범위

현행 서버 일정·카드 추첨표·지역 가격·노출 실험, 97개 튜토리얼의 서버 활동/원작 장면, 원작 전체 집 장면과 소리, 전체 영상 전수 검토는 확보된 근거만으로 확정하지 않는다. 연구 입력 예시와 실제 캡처 관측을 구분해 표시한다. APK/XAPK, 전체 복원 Lua, 원본 번들, 계정·플레이어 세션·자격 증명은 게시 대상에서 제외한다.
