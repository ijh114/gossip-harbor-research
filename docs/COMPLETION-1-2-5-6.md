## 검사와 저장

신규 순수모델·자료해시·60장면/25필수선택 순회·저장 복구·활동 정합·실제 버튼 이벤트 검사를 포함해 자동 검사295개를 통과했다. 패스 수령→앨범 완성→대표 이벤트6합성→보상까지 앱 DOM에서 확인했으며 메인 지갑 비간섭을 검사했다. 기존 순수게임모델·설정revision·기존 자연진행 기록은 유지했다.

선택적 `screenFlow`와 `activityPlay`를 같은 저장에 포함한다. 정의된 손상 활동값은 자동 교체하지 않으며 JSON보관/원본백업 후 명시적으로 활동만 초기화한다. 활동 타이머는 화면에 있는 동안 갱신하고, 실패·중복기록·만료 시 보상을 추가하지 않는다.

브라우저 직접 검수는 도구가 계속 “Work의 로컬 브라우저 사용 꺼짐”으로 응답해 미수행이다. 사용자가 켠 내장 브라우저 허용 스위치와 해당 Work설정은 별개임을 실제 연결시험과 설치앱의 한글 설정명으로 확인했다. DOM 검사를 실제 렌더·터치·청취·원작 실행 검증으로 표시하지 않는다.
