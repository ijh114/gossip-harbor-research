## 87종 실행 투영의 범위

소스 경로와 행·SHA를 각 단계/분기/콜백에 보존하며 가상의 REA Evidence ID는 만들지 않았다. 공개 파일은 필요한 제어 흐름·출처·독립 실행 코드이며 원본 APK/전체 Lua/번들/전체 로컬라이제이션은 포함하지 않는다.

`#tutorial-analysis`의 세 번째 묶음에서87개를 선택한다. 기본 컨텍스트는 `mode:research`뿐이며 실제 근거가 없는 모델/분기는 `unknown`으로 멈춘다. 일반 “다음”으로 미지원 단계를 건너뛰지 않는다. 원작 사건·현재 마스크 콜백·예약 시각·재접속/해제만 실행한다. 전용 저장 키는 메인 저장과 분리되고 손상 원본은 내보내기·백업 후 명시 초기화한다.

컨텍스트 없이 시작하면27종은 리스너만 준비되고60종은unknown이며 자동 완료0종이다. 87개 선언/프로그램이 있다는 사실을87개 실제 활동을 끝까지 플레이한 결과로 계산하지 않는다.

외부 연산은 초기147곳에서85곳으로 줄었다. 남은 분류는 UI입력/상태36, UI표현14, viewport8, 활동/영구 플래그20, 창 생명주기2, 애니메이션 후속4, 보드/경제 변경1이다. 매 요청의 인자 확보 여부와 원본 위치를 남기고 실제 적용 확인 없이 성공 처리하지 않는다. 강제 생성 코드/비용의 메인 엔진 어댑터가 없으면 실제 생성/소비도 차단한다.

## 회상 책 실물 재확인

ImageFileConfig45개 키(본문40·표지5)를 정확 매핑하고 기존245번들의10,037container·1,820Sprite에서 exact path/PPtr/이름을 대조했다. 기존 공개 자료에 연결되지 않았던 본문9개가 실제로 있어960×638 원본 RGBA PNG로 회수했다. 총3,679,235바이트이며 원본 bundle/Sprite 해시·픽셀 동일성·9개 이미지 육안 검수를 기록했다.

이전38개 “미확보”에는 공개 미연결 상태도 섞여 있었다. 현재는 본문11개 확보, 본문29키와표지5키는 제공 번들에서 exact 실물0으로 구분한다. 이 검색 결과가 원격 자산의 부재를 증명하지 않는다. 규칙 revision을 유지하고 별도mediaRevision으로 저장 호환성을 보존했다.

회상 기능의 기존 규칙은 새로 책을 열면1페이지, 읽음은 책 열기 때1회 기록, 현재과제는 해금과제보다 엄격히 뒤여야 한다. 새로고침의 현재페이지/남은 전환 유지와 화면 이탈의 표시 취소는 웹 정책으로 명시했다. 페이지 전체 원문을 게시하지 않고 매 페이지 최대80자 발췌1개와 생략 블록 수를 표시한다.

## 검증과 게시

전체 자동 검사 **489/489** 통과. 실제 웹 버튼/모달/포커스·저장·손상 보존·자동 회상·실제 공장 탭·지연/마스크·Lua 의미·전역 경쟁/제약·자산/출처 검사를 포함한다. DOM/합성 입력과 모델 검사를 네이티브 브라우저 시각·터치·청취나 원작 실행 검증으로 표시하지 않는다.

정적 빌드 **1050파일/74,298KiB**와 게시 경계 검사를 통과했다. 미연결 외부85연산의 안내ID·호출·출처는 전체 장부 부록E에 고정해 누락 없이 추적한다. 게시 후 두 호스트의 파일 해시를 대조한다. 공개 원본 경계와 LDPlayer 중단을 유지한다. 배포 기록은 별도 사적 `analysis/simulation/qa/work-0-3-deployment.json`에 보존한다.
