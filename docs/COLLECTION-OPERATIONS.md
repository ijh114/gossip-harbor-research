# 컬렉션 운영·자산 분석

기준일: 2026-11-03. 대상은 APK4.10.5 복구 코드와 해당 카탈로그에 정확히 연결한 자산, 기존 사용자 캡처다. 현재 계정의 활성 시즌·가격·확률·일정은 검증하지 않았다.

공개 페이지: [컬렉션](https://gossip-harbor-research.pages.dev/#collection)

## 운영 방식

시즌별 카드·세트·보상을 구성하고 주문·이벤트·상품에 팩을 배치해 수집을 이어가는 기간형 메타 콘텐츠다. 팩 공급량과 신규 카드 획득 속도를 별도로 관리한다. 시작→수집→세트/전체 완성→업그레이드/다회차→종료 정산으로 나눠 설명한다. 초반·중반·후반은 플레이 경험을 설명하는 분석 구분이다.

카드팩의 성급 슬롯, 카드별 weight, 연속 중복 보정, 신규 카드 수 제한, 단계별 pool이 결과에 함께 관여한다. 같은 팩을 모든 카드의 균등 독립 추첨으로 대체하지 않는다. 현재 서버 테이블을 확보하지 않아 기대 완성 비용·기간·무과금 완성률을 원작 값으로 산출하지 않는다.

## 카드 이미지와 제작 수량

| 자산 | moon | halloween | 합계 |
|---|---:|---:|---:|
| 카드 앞면 | 162 | 162 | 324 |
| 세트 표지 | 18 | 18 | 36 |
| 세트 배경 | 15 | 15 | 30 |
| 세트별 이름판/배경 | 18 | 18 | 36 |

도감은 테마·세트·이름/키 검색, 카드 확대, 전체 시즌 페이지 이동을 제공한다. 모든324개 앞면에 접근할 수 있으며 처음에는 선택한 세트9장을 표시해 화면·이미지 부하를 제한한다. 신규 난수 추첨이나 카드 지급을 실행하는 페이지가 아니다.

공용/기능 자산에는 팩24, 조커8, HUD7, Laser2, Rainbow1, Royal7, 테마 UI8개가 있다. 앨범 이미지 합계483키와 연관 이미지·프리팹·음향은 다른 단위다. 59개 프리팹에는 셀·툴팁·테스트 창도 포함된다. 기존 GH-S0362 캡처의135장 목표를 두 테마의162장 등록 범위와 구분한다.

신규 시즌 제작 산식은 세트 수×세트당 카드 수를 기본으로 삼고, 표지·장식·공용 프레임·NEW·중복 수량·FX·음향 재사용 범위를 별도 지정한다. 원작 수량을 신규 게임 발주 승인으로 취급하지 않는다.

## 콘텐츠 흐름과 플레이 루프

콘텐츠 흐름: 예고/시작→앨범/세트 목표 확인→팩 획득/보관→개봉→신규 또는 중복 처리→세트/앨범 보상→다음 회차 또는 종료.

플레이 루프: 에너지 소비→머지·주문 납품→팩→수집 진척→완성 보상→다시 퍼즐/이벤트.

중복→별 교환→보상과 필요한 팩→이벤트 참여→앨범 진척은 보조 루프다. Rainbow는 중복 시 조건부 점수 누적과 추가 카드 경로이며 조커처럼 대상을 직접 선택하는 기능과 다르다.

## 관련 BM

- 맞춤 카드 상품은 미완성 일반 세트의 누락4·5성을 분석해 후보를 만들고 구매 결과에서 한 장으로 세트를 완성하는 후보를 우선하는 경로가 있다. 모든 카드 자유선택 상품이 아니다.
- 맞춤 상품의 자동 노출은 일일 횟수·마지막 노출 후 대기·상품 상태·미수령 결과·IAP·전역 팝업 조건을 검사한다. 서버 하루 경계와 한국 자정을 동일시하지 않는다.
- 카드 진행 팩은 미결제 상태에서도 과제를 진행한다. 결제 후 완료 보상을 수령하며 종료 회수는 완료했으나 받지 않은 과제에 한한다.
- 별 교환은 필요 별·슬롯 쿨다운을 검사하고 남은 시간에 비례한 올림 젬 비용으로 대기를 건너뛴다.
- 조커는 종류·대상·시각 제한을 갖는다.24시간 경과 안내를 자동 삭제라고 해석하지 않는다.
- 업그레이드는 일반 카드와 그 중복을 초기화하는 한편 별도 보관 별·미개봉 팩·조커·Rainbow·활성 Royal을 보존하는 분기가 있다.

## 근거와 검증

`src/data/collection-study.json`의58개 선별 출처는 복구 코드 행·해시와 기존 카탈로그·회수 기록을 유지한다. 신규 게시물은 요약·메타데이터·기존 선정 축소 이미지만 사용한다. APK·전체 복구 Lua·번들·원본 영상·계정 자료는 공개하지 않는다.

자동 검사는 테마/세트 전수 접근324장, 페이지 중복/누락, 한글 검색, 검색 입력 유지, 빈 결과, 확대용 미디어 키, 자산 수량, 출처 참조, CSV와 기존 기능 회귀를 포함한다. 로컬 브라우저 연결이 비활성인 이번 세션의 직접 렌더·터치 검수는 미실시다. 반응형 CSS와 DOM 검사를 직접 PC/모바일 화면 검수로 표시하지 않는다.


## 보기 분리와 인터랙티브 구조도 (2026-11-03)

상단은 카드 컬렉션·앨범, 카드 컬렉션 도감, 활동 아이템 도감 비교의 세 보기다. `#collection`은 운영 방식부터 시작하고 `#collection?view=cards`는 카드324장의 이미지 탐색을 담당한다. 기존 카드 이미지 섹션 공유 링크도 도감으로 연결한다. 키보드 좌우/Home/End로 상단 보기를 이동하고 선택한 카드 검색 조건은 탭 왕복에서 유지한다.

앨범 분석은6개 운영 단계 선택기, 팩/조커→공통 획득→신규/중복의 분기 구조도,6개 노드 순환 그래프,483개 이미지 등록 키의 구성 그래프,4가지 BM 상황과 결제 전후 비교를 제공한다. 실제 이벤트 로그를 측정한 흐름량이나 라이브 확률·가격을 만들지 않는다. 원본 처리 규칙의 상세 설명·수량표·개별 상품 분석·출처는 접이식으로 유지한다.

작은 화면의 순환 그래프는 같은 순서의 번호 버튼과 설명으로 제공하며, 모든 선택은 키보드로 작동한다. 사용자 동작에 대한180ms 상태 피드백만 사용하고 reduced-motion에서는 제거한다. 기존 원작 시뮬레이션·유저 저장·경제는 수정하지 않는다.
