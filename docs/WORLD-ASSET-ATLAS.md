# 맵·NPC 시각 도감

2026-11-03. Gossip Harbor 4.10.5의 기존 확보 APK·카탈로그 리소스를 정적으로 분석했다. 원작 실행, 현재 운영값, 원작 shader/조명/최종 화면 검증은 포함하지 않는다.

## 페이지와 사용 방법

- `#world-atlas?tab=map`: 구역·종류·자산 단위·이름/경로로 필터, 36개씩 표시. 전체 필터 결과를 CSV로 저장한다.
- `#world-atlas?tab=npc`: 전신44 역할과 식당 손님6세트를 한 목록에서 비교한다. 인물/동물/차량/복합 연출/작업·의상 변형/손님을 구분한다.
- `#world-atlas?tab=motion`: 903개 모션을 골격·접미사·이름으로 필터, 24개씩 표시한다. 긴 모션은 카드의 ‘모든 구간’에서 전체 구간을 연다.
- `#world-assets`: 기존 수량 분석·출시 제작량 계산기. 네 화면은 공통 상단 링크로 연결한다.

맵의 개별 이미지를 확대하고, 모델에 연결된 프리팹 재질 예시와 단독 기하를 구분해 볼 수 있다. NPC·모션은 보이는 GIF만 자동 재생하며 전체 일시정지, 화면 밖 정지, 모션 감소 설정을 지원한다. 목록 상태는 hash URL에 남긴다. CSV는 현재 페이지가 아닌 현재 필터의 전체 목록이다.

## 파생 이미지와 정확도 경계

맵은 원본 Mesh/UV/재질/Transform을 읽어384px 정사영 미리보기로 만든다. 프리팹의 비활성 자식과 비표시 Renderer를 제외하고, 선택한 자산 루트는 독립 검사 대상으로 표시한다. 원작 카메라, shader, PMA/투명 합성, 광원, 그림자, 입자와 애니메이션 변형을 재현한 화면은 아니다. SkinnedMesh는 정적 기하만 표시한다. 모델 재질 예시는 정확한 모든 Mesh SHA 포함 관계로 연결하며 이름 유사성으로 연결하지 않는다. 연결된 프리팹의 다른 부품이 함께 보일 수 있다.

손님은 Spine3.8 골격의 선언 클립을 전체 시간에 걸쳐8FPS와 종료 지점에서 샘플링했다. Spine의 top-down UV와 공통 Mesh 렌더러의 bottom-up UV를 명시적으로 변환한다. 실제 좌석 부모 Transform·상하체 분할 재생은 별도다. Lucy의 대표 이미지만 선언된 상·하체를 같은 골격 좌표에 합성했다. 원본15개 클립은 모션 목록에 분리 보존한다. Celia/Riley의 시작 모션명 불일치는 원본 기록으로 남기며 임의의 동일성 판정을 하지 않는다.

전신 모션은 기존 확보·검사된 파생 GIF/프레임을 재사용한다. 긴 모션의 모든 분할 구간 링크를 유지한다. 도감의 반복은 탐색용이며 원작의 loop 설정·전이 조건을 관측했다는 뜻이 아니다.

## 재현과 게시 범위

로컬 분석: `analysis/world-atlas-20261103/`. 주요 도구는 `render_maps.py`, `raster.cpp`, `sample_customers.cjs`, `render_customers.py`, `render_customer_pair.py`, `build_catalog.py`. 소스·도구·결과 해시는 `src/data/world-atlas.json`의 sources와 개별 레코드에 보존한다. 기존 원본 분석·리소스 보관소를 변경하지 않는다.

게시물은 도감 메타데이터와 선별 WebP/PNG/GIF다. 번들, APK, 원본 모델/골격, 전체 복원 코드, 개인 경로·사용자 데이터는 게시하지 않는다. 단위·분류/범위·SHA를 유지하며 제작 수량 초안과 원작 재생 검증은 각각 별도로 관리한다.

검증은 전체 레코드 페이지 도달성·필터·CSV·긴 모션 구간·전체 신규 미디어 SHA/바이트·앱 통합 및 브라우저 이미지/확대/반응형 동선을 포함한다. 원작 실행 검증을 완료로 승격하지 않는다.
