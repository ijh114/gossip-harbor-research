> 이 문서는 해당 작업 시점의 구현·검수 기록 또는 당시 설계다. **고정 ID와 현재 완료 판정은 [전체 작업 장부](MASTER-CHECKLIST.md)를 기준으로 읽는다.** 과거 수치·완료 표현으로 현재 상위 작업 전체가 완료됐다고 판정하지 않는다.

# 시각 탐색 영역과 연구 문서 분리

사용자 요청(2026-10-28)에 따른 구현 범위다. 기존 녹색/한글 서체 시스템과 정적 배포 구조를 유지한다.

- **연구**: 전용 색인 페이지와 접이식 하위 트리. 개요, 난이도 설계부터 재화·성장까지 10개 분석 페이지, 전체 근거 위키·상품·트리거·규칙 실험·Unity 이식 문서를 전부 이곳에 둔다. 기존 hash URL은 유지한다.
- **퍼즐**: 타입 도감과 연출 갤러리. 하위 페이지는 상호작용·난이도. 복원한 아이템 설정의 타입/변형 목록과 검증된 동작을 연결한다. 이름/이미지가 미확인된 타입은 ID로 표시한다.
- **UI**: 하위 구조·연출. 구조는 클릭 가능한 배치 모식도와 컴포넌트 목록, 연출은 카드별 재생 가능한 웹 시연과 실제 캡처 슬롯으로 구성한다. 화면 좌표·원화·실기 시간은 미관측임을 표시한다.
- **게임 시뮬레이션**: 로딩 → 타이틀 → 튜토리얼 → 메인 → 게임 플레이 → 집 발전/변화의 연결 프로토타입. 기존 독립 보드 엔진을 재사용하되 원작 전체 재현이라고 표시하지 않는다. 플레이 행동과 재화·집 상태가 연동되어야 한다.
- **미디어**: 이미지/GIF/영상 manifest를 둔다. 지금은 제공되지 않은 캡처를 대기 상태로 표시한다. 검토 전 로컬 파일의 자동 게시/업로드는 하지 않는다. 타입/컴포넌트 키, 장면, 출처, 시점, 메모로 이후 캡처를 연결한다. GIF 자동 반복 대신 명시적 재생/정지를 제공한다.

선택: 기존 앱 안의 새 갤러리/흐름 모듈로 확장한다. 별도 앱은 출처 연결과 동일 소스 이중 배포를 복잡하게 하고, 기존 문서에 카드만 추가하는 방식은 사용자가 요청한 시각 탐색/상세 연구의 분리를 달성하지 못한다.

순서: 탐색 구조 → 큐레이션한 타입/UI 목록 → 갤러리와 동작 시연 → 배치 모식도/난이도 차트 → 연결 플레이 흐름 → 매니페스트 연결 → 기능/출처/빌드 검사 → GitHub 및 Cloudflare 배포. 기존 데이터·문서·다운로드와 링크를 회귀 검사한다. 현재 브라우저 도구의 로컬 접근은 꺼져 있어 실제 렌더 검수는 별도로 남는다.

## 구현 및 검증 결과

위 구조를 기존 앱에 구현했다. 새 시작 화면은 퍼즐 도감이며 연구 자료의 기존 hash는 유지한다. 타입 도감은 39개 설정표 4,270개 선언, UI 도감은 1,644개 연결 선언을 검색/분류/페이지 단위로 탐색한다. 실제 캡처 등록은 아직 0건이다. 8개 퍼즐 동작과 6개 UI 동작은 명시적 재생/정지가 있는 도형 모식도로 제공한다.

기능 검사 21개, 정적 빌드, 자료 출처/배포 경계 검사를 통과했다. 새 UI에 대한 DOM 검사에는 메뉴 트리, 타입 검색, 시연 시작/정지, 상호작용 선택, 난이도 차트, UI 영역 선택과 흐름 단계 이동을 포함한다. 순수 상태 검사에서는 실제 생성·합성·주문 5회를 거쳐 얻은 200골드 중 180골드를 세 단계 공간 변화에 소비했다.

브라우저 도구는 이번 요청에서도 로컬 브라우저 사용 비활성 상태를 반환했다. 따라서 이 결과는 실제 렌더 스크린샷, 터치 제스처, 브라우저 애니메이션의 육안 검수를 포함하지 않는다.
