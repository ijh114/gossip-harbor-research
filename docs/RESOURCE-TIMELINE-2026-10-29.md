## 시간축을 새로 검토해 확인한 것

원본 캡처의 앱 버전과 실제 촬영일은 미확인이다. 아래는 과거 녹화의 특정 구간 관측이며 APK4.10.5의 실행 검증 또는 모든 유저의 공통 서버 조건으로 일반화하지 않는다.

- GH-V0064의 레벨104 보상 팝업 수령 뒤 381초대에 레벨104 축하 번들과 ₩49,000 표시가 보인다. 레벨업→상품의 한 관측 순서이며 보편 트리거·빈도·실제 결제 성공은 확정하지 않는다.
- GH-V0125의 단계형 판매는 단순 배너 외에 단계 타일·가격/수령/체크 상태와 상자/선물 개봉 변형을 포함한다.
- GH-V0106·0121의 전면 보상에는 배경·상자·동물·다중 결과·리본이 별도 구성 요소로 보인다.
- GH-V0121·0122의 팩 개봉과 다중/단일 카드 결과는 카드 원화와 별도의 제작 항목이다.
- GH-V0113의 맵 장식 선택과 GH-V0115의 전용 이벤트 보드는 선택/확인 UI·테마판·아이템·진행/수집 화면·VFX를 추가로 요구한다.
- GH-V0117의 도구 시연은 도움말 안 반복 시연이다. 실제 보드에서 도구를 사용한 증거로 바꾸지 않는다.

약0.5초 목표 표본의 최대 실측 간격은1.493112초다. 원본의 가변 프레임 시각과 기록 공백을 반영한다. 디코드 프레임 수, 육안으로 검토한 표본, 원속도 재생, 오디오 측정/청취를 별도 카운터로 공개한다. 원본/정리본은 수정하지 않으며 전체 영상과 검토 시트는 게시하지 않는다.

## 기능과 검증

`npm test` **254/254 통과**, `npm run build` **694파일/43,397KiB**, `npm run check` 통과. 영상 원본113개 해시·선언/디코드 프레임·시트 해시·PTS·전시간 리뷰 장부·추가 끝점6개의 검증 오류는0이다.

순수 제작 계획은 HTML/네트워크와 분리했다. 선택한 범위의 항목만 내보내며 아이콘·세트·모션·곡 등의 단위를 합산해 총 그림 수/공수로 표시하지 않는다. 수량은0–10,000 정수다. 잘못된 수량이 있는 항목이 검색에서 숨겨져 있어도 해당 항목으로 돌아가 수정하기 전 내보내기를 막는다. 범위를 바꾸어도 직접 편집한 규격·수량·사용자 메모를 보존한다.

DOM 통합 검사에서 신규 탐색, 범위27/40개 전환, 영상 ID 직접 연결/자동 펼침, 기존 도감·재생·게임형 플레이 탐색을 확인한다. 데이터 검사는 원작 측정 PNG 해시와 크기, 관측 구간/원본 해시, 문서의 현재 작업 수치를 대조한다. CSV는 한국어 BOM과 수식 시작 문자 이스케이프를 포함한다.

**이번 변경의 실제 브라우저 시각 검수는 미완료다.** Work에서 로컬 브라우저 사용이 꺼져 있어 제어 가능한 브라우저 목록이 비어 있다. 권한 설정은 변경하지 않았다. 기존 변경의 Chrome 검수 기록과 이번 DOM 검사를 구분한다.

게시 소스는 동일한 `main`에서 GitHub Pages/Cloudflare Git 연동으로 배포한다. 게시 성공은 각 서비스 실행 상태와 새 모듈·데이터·측정 이미지 응답의 SHA-256을 커밋 내용과 비교하여 별도로 확인한다.
