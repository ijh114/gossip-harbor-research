## 자료를 보는 방법

[실제 화면·관측 자료](https://gossip-harbor-research.pages.dev/#captures)에서 분류와 검색으로 정밀 자료를 선택한다. 원본 프레임을 바꾸면 해당 프레임의 주석도 함께 바뀐다. 작은 주석 사각형 외에 텍스트 버튼으로 영역을 선택할 수 있다. 썸네일 선택창의 GIF는 보일 때만 재생하며 전체 일시정지·움직임 줄이기·접힌 창/다른 페이지에서 정지를 지원한다.

퍼즐 상호작용·연출, UI 구조·연출, 맵·맵 연출, 이벤트 문서와 제작 요청 항목에서도 관련 정밀 자료로 이동한다. 기존12개 상호작용 GIF와42개 과거 선정 파생 자료는 그대로 보존하고 신규 자료는 별도 manifest로 관리한다.

## 원본 시각과 측정의 의미

- 공개 영상/GIF의 프레임 레이트와 원본의 PTS를 구분한다. 정밀 관측은 원본 프레임의 시각을 기준으로 한다.
- 신규 반복 GIF에는 비교를 위한 시작/끝 정지 구간이 포함된다. GIF의 전체 재생 길이로 원작 연출 시간을 측정하지 않는다. 원본 시간 척도의 MP4와 실제 프레임 PTS를 함께 제공한다.
- 화면 변화가 처음 드러나는 프레임과 안정되는 프레임은 관측할 수 있지만, 손 입력 로그가 없으면 정확한 클릭·드래그 임계치·입력 잠금 기간을 확정할 수 없다.
- 측정은 선정한 사례의 구간이다. 반복 실험 분포나 모든 기기/계정의 공통 시간으로 쓰지 않는다.
- 맵 변화3쌍은 같은 녹화의 같은 작업 위치를 확인했다. 카메라 이동·확대·인물 차이가 있어 픽셀 정합 차이 슬라이더 대신 나란히 비교한다.
- UI 주석은 크롭 후 이미지 기준0..1의 분석가 사각형이다. 실제 터치 영역·프리팹 앵커·게임 월드 좌표가 아니다.
- 도움말 안 반복 시연과 실제 보드 사용을 구분한다. 표본이 없는 동작에는 기존 APK 규칙 재현을 유지하며 실제 영상으로 바꾸어 표시하지 않는다.

## 음향

110개 녹화 전체에0.2초 RMS/peak 시간축·LUFS/LRA·저음량 구간·에너지 상승 후보를 기록했다. 오디오 첫 샘플의 시작 시각을 더해 영상 PTS 축과 맞춘다. 컨테이너 길이와 실제 디코드된 오디오 길이는 다르다. 에너지 상승은 클릭/합성/대사 판정이 아니며 디코드 overshoot를 원본의 클리핑이라고 확정하지 않는다.

이 세션은 오디오 입력을 지원하지 않아 **직접 청취·전사·음색/악기 판정은0초/미확인**이다. 공개 재생 자료는 APK 동봉 효과음12개와 BGM2개의 각6초 발췌다. 이름과 정적 호출 경로로 용도를 설명하고 파형·주파수 분포를 제공한다. 녹화의 혼합 음향은 공개하지 않는다.

녹화별 그래프에서 분석 시각을 움직이면 해당 bin의 수치와 기존 화면 장부의 장면이 나타난다. 이는 정량 비교이며 청취를 대신하지 않는다. 신규 게임용 음향은 별도로 제작한다.

세 녹화에서는 APK 원WAV와 혼합음의 정규화 상호상관을 비교했다. 샘플레이트/필터를 바꾸고 역재생 대조를 함께 계산해 대표 신호 유사도 후보5개, 보류2개, 구별되는 일치가 없는2개를 보존한다. 144회 비교 후 선정한 탐색 결과이며 통계적 식별 정확도·확정 청취 판정이 아니다. 낮은 일치를 소리나 구매가 없다는 증거로 쓰지 않는다. 후보 음원의 시작 추정은 템플릿 앞의 트림 길이와 오디오 offset을 반영한다.

## 출처·정정·공개 경계

`src/data/media-refinement.json`에 원본 ID/SHA-256, 실제 프레임 PTS, 크롭, 파생 파일 해시, 관측과 미확인 사항을 보존한다. 정밀 검토로 이전 분산/시간순 표본의 해석이 바뀌면 이전 분류와 새 근거를 정정 이력으로 남긴다. 과거 관측을 조용히 다른 주장으로 덮어쓰지 않는다.

원본/정리본은 수정하지 않는다. 전체 영상·검토 시트·원본 녹화 음원·APK·전체 번들·계정/OS/외부 결제 화면은 게시하지 않는다. 촬영 버전·촬영일·현재 서버 배정은 계속 미확인이다.
