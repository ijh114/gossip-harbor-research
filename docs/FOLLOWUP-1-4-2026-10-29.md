## 안내와 Skin의 사용법

게임 시뮬레이션의 **플레이에 연결한 추가 안내**에서 안내를 선택하고 연구 예제 또는 명시 JSON을 연결한다. 현재 웹 모드·열린 과제 창·일반 강제 안내 상태는 어댑터가 갱신한다. 서버·활동·해금값은 입력한 연구값으로 남기며 원작 계정 값으로 자동 승격하지 않는다.

- 부스트: 퍼즐 진입과 성공한 배율 변경을 간단 부스트 안내에 연결한다.
- 패스: 시작한 연구 시즌의 패스 진입을 연결한다. 설명/수령권 강조 콜백은 결제와 별도다.
- 회상: 실제 웹 과제 목록의 열기·닫기와 설명 단계를 연결한다. 원작 전체 회상 책을 복원한 것은 아니다.
- 공장: 폴링·조각 탭은 명시 연구 예제이며 보관함 강조와 비교한다. 실제 공장 생산/조각 이동을 구현했다고 표시하지 않는다.
- 장식: Skin 연구에서 같은 슬롯의 소유가2개 이상 명시된 보상 이벤트를 장식 변경 안내에 연결한다.

추가 독립5종은8배 부스트 시작·주간 과제 추가 별·패스 추가 과제·과제 추가 보상 입구·생성기 부스트 활성이다. 등록상 완료와 화면 완료,0.6/1/1.5초 정적 지연·재검사·조기 종료를 보존한다. 누락 컨텍스트는 unknown으로 차단한다. 두 연구 묶음과 플레이 연결의 저장은 서로 다른 용도이며 원작 전역 안내 우선순위를 재현하지 않는다.

메인 맵→장식 기록→**Skin 소유권·세트 연구**에서 동봉2세트26개를 선택한다. 소유권 버튼은 명시 연구 지급이며 구매/지갑과 연결하지 않는다. 세트 미리보기는13개 연동 슬롯의 별도 초안이다. 취소는 기존 기록을 유지하고, 확정은 해당 연구 슬롯만 원자적으로 바꾼다. 미소유 단일 장식은 적용하지 않는다. 일괄 확정의 전 소유 조건은 보수적인 웹 제한이며 원작 전체세트 버튼에 같은 guard가 있다고 주장하지 않는다. Skin 그림은 미확보이므로 ID 관계만 표시한다.

정의된 손상 `tutorialBridge`/`skinLab` 값은 자동 교체하지 않는다. JSON 보관·명시 백업/초기화·이탈이 가능하다. 편집 중 다른 세트로 바꾸는 동작은 취소/확정 후에 허용한다.
