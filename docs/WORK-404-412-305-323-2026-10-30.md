## 검증과 복귀 정책

기존 자연/고정16/확장/후기/이어하기/seed7·83의7개 private trace를 현재 모델에서 재실행했다. 성공 명령386,664개와 전후 스냅샷773,328개의 경제·보드SHA·RNG·validPlay가 일치하고 Lv26/210과제 최종 결과도 동일하다. 원본7보고서와 이전 공개3요약을 백업·보존했다. 새 소비기는 적용 범위 밖에서 기존 경제를 바꾸지 않는다. 상호작용12개 상태 fixture도 재실행 결과가 같아 기존 GIF 바이트를 유지하고 출처 해시만 새 실행에 연결했다.

Skin 장부는 snapshot SHA와 영수증 재계산·동일 요청1회·잔액·소유권을 확인한다. 저장 전에 소유권을 노출하지 않고 다른 탭의 저장과 충돌하면 거래를 거절한다. 이미 저장한 거래의 맵 연결만 실패하면 영수증에서 다시 동기화하며 재차 차감하지 않는다. 읽지 못하거나 호환되지 않는 저장을 자동 덮어쓰지 않는다.

회상 책은 논리 잠금과 시연 모션을 별도로 관리한다. 신규 책 열기/복원에 기본 nextPage 영상을 자동 배정하지 않는다. 탭 숨김·화면 이탈에서 자동 시연을 취소하고, 저장된 페이지/입력 잠금 잔여시간만 웹 정책으로 재개한다. 원작 native queue/mix를 합성한 영상과 구분한다.

공개 파생은 이미지·축소 무음영상과 출처 메타로 제한한다. APK/XAPK·bundle·전체 복원Lua·원본 geometry·사용자 계정/개인 저장은 공개하지 않는다. 최신 판정은 [전체100항목 장부](MASTER-CHECKLIST.md)와 웹의 #checklist에서 같은ID로 관리한다.
