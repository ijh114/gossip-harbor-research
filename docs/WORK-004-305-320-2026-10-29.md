# 0.04 · 3.05~3.20 작업 기록

기준은 [고정 전체 작업 장부](MASTER-CHECKLIST.md)의 17개 기존 항목이다. 3.21 이후나 Unity 이식을 이번 요청에 새로 포함하지 않는다. 이미 완료한 3.09·3.11·3.12·3.17은 회귀 검사하고, 같은 ID의 미완료 구현·자료를 계속 추적한다.

## 시각 표현의 구분

기존 캡처는 원작 영상의 참고 화면이며 빌드 일치가 미확인이다. 새 맵은 MapView의 원본 계층·슬롯·prefab TRS를 합성한 공통 정적 투영이다. APK 정적 기하를 사용했다는 사실과 원작 카메라·조명·셰이더·활성 상태 일치를 구분한다. 전체 geometry·복원 Lua·번들은 공개하지 않고 선별한 PNG 레이어만 게시한다.

완료한 과제의 명시된 디자인만 해당 슬롯에 반영한다. 미완료 슬롯의 0번은 MapLayer와 MapConfig가 정의한 초기 경로를 확인한 경우만 표시한다. 완료했지만 이전 웹 저장에 선택 기록이 없는 슬롯을 임의의 0/1번 디자인으로 채우지 않는다. 맵에서 연 장식 편집은 같은 위치에서 미리 보고 취소·확정한 뒤 맵으로 돌아온다. 편집은 과제·경험치·재화를 다시 지급하지 않는다.

새 인트로는 Timeline_intro의 마스크·카메라·선정 대사·생략 단계·종료 순서로 진행한다. 선언 시간 재생과 수동 연구 이동을 구분하며 타이틀 이동·새로고침 후 같은 명령으로 복귀한다. 원본 CG 프리팹과 인트로 타임라인의 연결이 확인되지 않으면 같은 장면이라고 매핑하지 않는다. 전체 대사 대신 기존 발췌·생략 정책을 유지한다.

## 활동과 경제

기존 분리 연구 시즌은 보존한다. 추가 설정형 시즌은 일정·과제·패스·앨범·대표 이벤트 설정의 출처를 표시한다. 연구 예시를 사용자 확정 출시값이나 원작 계정의 실운영값으로 바꾸어 부르지 않는다. 메인 모의 경제 연결은 현재 설정을 명시적으로 수락한 경우만 활성화한다. 원자 거래와 지급 영수증으로 비용·보상·진행의 일부만 반영되는 상태 및 중복 지급을 방지한다. 실제 계정·게임 서버·SDK·IAP·광고는 연결하지 않는다.

## 직접 검수 경계

2026-10-29에 CUA로 재확인한 브라우저 상태는 `Local browser use is disabled in Work settings`였다. 해당 제한을 다른 브라우저 제어 경로로 우회하지 않는다. 모델·DOM·이미지 파일 검사와 실제 브라우저 렌더·터치·청취 검수를 구분한다. LDPlayer 분석 중단은 유지한다.

## 검증

자동 검사 **561/561개**, 정적 빌드 **1219파일/91,603KiB**와 게시 경계 검사를 통과했다. 원본 핵심11개 규칙/경제/저장 모듈과 기본 config revision은 유지했다. DOM검사는 실제 공장3단계·Finish 뒤 후속효과, 자동회상, 설정 수락/카드팩 보상/재접속 중복 방지, 메인 성공 기록 outbox·큐한도 롤백, CG/인트로 왕복을 포함한다.

예약 poll을 반복 평가하며 화면과 메모리가 늘어나던 결함은 현재 시각의 예약 처리를 마친 후 unchanged로 수렴하게 수정했다. 새DOM 대상 수집 전에 옛 노드로 입력을 판정하던 문제도 수정했다.

공개 자료는 공통 지도125개·CG22개·native4개=151이미지 참조(기존 CG2개 재사용), 회상 페이지 WAV1개다. native MapCamera는 약37° 방향의 perspective/FOV19.455158°이며 웹지도는40° 직교 투영이다. 추가 회수한 builtin 바다 Quad의 _SeaColor-only 정적 실험은 가시픽셀0이므로 임의 바다 그림을 추가하지 않았다.

두 호스트의 동일 커밋 배포와 파일SHA 대조는 사적 analysis/simulation/qa/work-004-305-320-deployment.json에 기록한다. 원본 전체 geometry·native serialized·전체Lua/번들·전체문구는 게시하지 않는다.
