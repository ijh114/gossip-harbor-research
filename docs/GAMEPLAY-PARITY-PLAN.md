# 실제 게임형 플레이 후속 구현

사용자의 명시적 목표는 실제 게임과 같은 웹 플레이이다. 이번 구현은 제공 캡처의 모바일 화면 구성을 기준으로 삼고 실제 APK 규칙을 적용하는 단계다. 완전한 동일성을 미리 선언하지 않는다.

1. 게임 플레이 화면: 자원HUD → 손님/주문 →7×9보드 → 선택 아이템/하단 행동. 드래그와 탭·키보드 입력을 함께 제공한다. 연구 메뉴·로그·가정 입력은 게임 화면 밖에서 유지한다.
2. 초기 흐름: 원본 초기판과 shipped 튜토리얼로 확인한 입력 순서, 생성 위치/강제 산출을 적용한다. 기존 연구용 저장은 그대로 복원하고 새 게임을 강제로 덮어쓰지 않는다.
3. 기믹·경제: 수집 재화, 가위/레벨업도구, 시간 단축 등 결정론 규칙을 적용한다. 소스에 없는 아이템/확률/보상은 만들지 않는다.
4. 성장: 기본 분기의 초반 과제를 늘리고 자연 레벨 성장에 필요한 실제 골드/재화 수집을 연결한다. 동적 주문/서버 일정·계정 배정은 별도 차이로 남긴다.
5. 비교표: 입력·생성·특수도구·HUD/주문/맵·BM을 소스 구현/캡처 참고/웹 재구성/미확인으로 구분한다. 시각 검수와 상태 전이 테스트 후 두 호스트에 배포한다.

시각은 기존 위키의 정체성과 별개로 **제공된 실제 게임 화면**을 따르는 로컬 확장이다. 새로운 아트 방향을 임의로 선택하지 않는다. 원작 로컬 Sprite의 선정 UI 요소를 재사용하며 미복구된 폰트·레이아웃·캐릭터 동작·스토리 장면은 근사/미구현으로 기록한다. 구현 선택은 원래 데이터와 별도로 문서화한다.
