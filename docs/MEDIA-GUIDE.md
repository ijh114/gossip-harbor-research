# 이미지·GIF·영상 연결 안내

최신 정밀 자료는 [MEDIA-REFINEMENT.md](MEDIA-REFINEMENT.md)를 따른다. `media-refinement.json`의25개 연구·신규 시각86참조·동봉 음향14발췌는 아래 기존 manifest의42개 과거 선정 자료와 분리한다. 프레임별 주석과 음향 그래프는 원본 녹화 시각/해시를 보존하고 직접 청취 미확인 경계를 유지한다.

`src/data/media.json`에 APK 정적 이미지와 과거 사용자 캡처를 각각 등록했다. `#captures`에서 주제/형식 필터와 실제 화면을 볼 수 있다. 갤러리의 웹 모식도와 독립 시뮬레이션은 원작 영상과 별도로 표시한다. 같은 소스로 GitHub Pages와 Cloudflare Pages에 게시하며 로컬 디스크 경로를 웹 URL에 넣지 않는다.

## 등록 구조

검토한 파일을 `src/assets/media/` 안에 넣고, 파일명은 영문·숫자·하이픈으로 정리한다. 정지 이미지 PNG/JPEG/WebP, GIF, 영상 MP4/WebM을 지원한다. 일반 GIF·영상은 사용자가 재생을 요청할 때 연다. `#puzzle-interaction`의 `interaction:*` GIF는 사용자 요청에 따라 보이는 카드만 자동 반복 재생하며 전체 일시정지·움직임 줄이기·화면 밖 정지를 제공한다. 모든 반복 GIF에는 정지 `poster`를 둔다.

```json
{
  "key": "effect:merge",
  "kind": "gif",
  "src": "./assets/media/merge-01.gif",
  "poster": "./assets/media/merge-01-poster.webp",
  "alt": "동일 아이템 두 개의 합성과 결과 팝 연출",
  "source": "사용자 제공 플레이 영상 파일명 · 00:12–00:15",
  "capturedAt": "실제 촬영 일시를 아는 경우만 기입",
  "version": "실제 촬영 게임 버전을 아는 경우만 기입",
  "notes": "기기·계정 진행·실험 조건·확인할 내용"
}
```

위 객체를 manifest의 `entries` 배열에 추가한다. 예시 자체는 등록된 캡처가 아니다. 동일 키는 한 번만 등록하고 대표 자료를 지정한다. `alt`와 `source`는 필수이며 시점·버전을 모르면 추정하지 않는다.

## 조사 연결

이미지에서 실제 배치·색·아이템 외형을 확인하고, 영상에서 상태 전후·입력·연출 시작/끝을 기록한다. 가격·오퍼 노출은 계정 진행, 재화, 결제 이력, 이벤트와 시각에 따라 달라질 수 있으므로 캡처 한 건을 일반 규칙으로 바꾸지 않는다. 연구의 정적 코드/내장 설정/문구/추론 구분도 유지한다.

내장 아이템 도감은 `Type`이 있는 39개 ItemModelConfig 계열 테이블의 4,270개 선언이다. 같은 타입의 변형도 포함하며 유일한 이미지 4,270장을 확보했다는 뜻은 아니다. 생성기 여부는 `Spread_` 필드의 존재로 분류한 탐색용 역할이다. UI 1,644건은 프리팹 연결 선언이며 실제 표시된 화면 수가 아니다.

자료를 연결한 뒤 `npm test`, `npm run build`, `npm run check`를 실행하고, 재생·정지·크게 보기와 휴대폰 크기에서의 화면을 확인한다. 원본 APK·복원 Lua 전체·플레이어 개인정보는 배포 자료에 넣지 않는다.

## 현재 연결 범위 · 2026-10-29

패키지 이미지 참조599키, 기본타입544/552개·3201별도6변형·미확보8사유를 연결했다. 과거 캡처42키는 정지30·영상11·GIF1이며 규칙 재현GIF11키와 구분한다. 상호작용12카드의1개만 실제 캡처 발췌이고11개는 원본 Sprite와 규칙으로 만든 재현이다. `origin: apk-rule-replay`에는 모델/설정/상태fixture·Sprite 해시와 설명용 시간임을 기록한다. 자세한 범위는 [퍼즐 도감 구성](PUZZLE-GALLERIES.md)과 [현재 대응표](GAMEPLAY-PARITY-VALIDATION.md)를 따른다.

아래 정적 이미지24개/기본71개 등의 수치는 초기 연결 작업의 이력이며 현재 총수로 사용하지 않는다. 같은파일중복참조를고유이미지로세지않는다.

## 전 구간 시간순 표본 검토

`src/data/media-audit.json`과 `#media-audit`는 전체113개·5,705.013초의 디코드 기록과 가십하버110개·5,657.265초의 시간순 표본 1차 시각 검토를 구분한다. 타게임3개·47.748초는 연구 통계에서 제외한다. 전체624,314프레임을 디코드했으며 전체11,262표본·236시트, 연구 대상621,147프레임·11,167표본·233시트다. 6개 영상은 실제 마지막 프레임도 추가 추출·직접 확인했다. 모든 원본 해시를 재대조하고 회전 메타데이터가 있는3개 영상은 검토 시트 방향만 보정했다.

표본 선택 목표는 약0.5초 간격이지만 원본 가변 프레임/공백 때문에 실제 최대 간격은1.493112초다. 컨테이너 종료 시각과 마지막 영상 프레임/표본 시각도 구분한다. 장부의 구간은 해당 시간축을 표본으로 검토한 범위이며 원속도 전체 재생·모든 프레임 육안 판독을 뜻하지 않는다. 오디오 트랙과 음량은 측정했지만 청취·대사 전사는 수행하지 않았다.

원본과 검토 시트는 게시하지 않는다. 공개 장부는 ID·해시·기술 요약·관측·미확인 사항과 기존 선정 파생본의 연결만 포함한다. `#media-audit?source=GH-V0121`처럼 ID로 직접 열 수 있으며, 제작 페이지20개 행에 발주 판단을 돕는8개 관측을 연결했다. 촬영일·앱 버전은 계속 미확인이다.

## APK 정적 이미지 · 초기 연결 이력

추가된 원본 PNG24개는 `origin: packaged-sprite`로 구분하며 `sha256`과 Sprite객체/번들 출처를 보존합니다. `asset:이름`24개와 명시적인 기본타입20개가 같은 파일을 참조하여 총44키입니다. 이는 화면 캡처나44개 고유 이미지가 아닙니다.

## 사용자 제공 캡처

영상 보류는 해제되었다. `origin: observed-user-capture`, `version: null`, `capturedAt: null`로 과거 화면임을 표시한다. `originalSha256`은 원본, `sha256`은 공개 파생본을 식별한다. 영상의 `sourceRange`는 발췌 시작/종료이며 `transform`은 크롭·크기·24fps·무음·원속도를 기록한다. 정확한 입력 시각이나 원작 프레임 시간을 측정한 값이 아니다.

원본/정리본은 하드링크이므로 직접 편집하지 않는다. 공개용 파생본에서 상단 계정 식별 워터마크와 OS 알림을 제외하고, 결제 화면 전체·개인정보·로컬 경로·검토용 연락 시트를 배포하지 않는다. 보상 대기열은 UI 팝업 FIFO와 다르고 체인의 무료 보상 잠금은 퍼즐 봉인 해제와 다르므로 대응하지 않는 `effect:*`키를 쓰지 않는다.
