# 설정 기반 웹 플레이 검증 · 2026-10-28

## 구현한 연결

기존 `#experience`에 APK 설정 기반 모드를 추가하고 로딩/타이틀/튜토리얼/집 발전의 기존 흐름 시연을 유지했다. 기본 Type552종의 identity/합성/판매가를 좁게 투영했다. 선정6체인65종은 정확한 Sprite를 연결했다. 다른6타입의 기존 연결까지 기본 타입 이미지71개이며 고유PNG75개/미디어 참조95개와 구분한다.

선정 생성기16종의 타입별 공유 소진 풀, 개별 생성기의 item/storage 잔여량과2단계 회복을 적용했다. 원본7×9 덮개판과 연구용 열린 배치를 선택한다. 클릭 두 번으로 합성/이동하며 생성기를 다시 누르거나 생성 버튼을 사용한다. 충전량·풀·RNG는 실패 입력으로 소비되지 않는다.

처음16개 고정 주문의 요구 타입/중복 개수/기본 골드/해금 레벨을 사용한다. 슬롯별 병렬 배정은 단일 연구 목록으로 축약했다. 기본 MainTask 첫6개는 비용26/16/24/46/25/24와 EXP15를 적용한다. 시작과 장면 완료를 분리하고 확정 시 한 번만 소비/보상을 적용한다.6과제 후Lv3/EXP15이므로 마지막3개 주문의Lv4조건은 명시적 EXP 도우미로 실험한다. 자연 성장 완성을 주장하지 않는다.

플레이 에너지와 무료 잔여/현재 젬 가격을 충전·닫기 후 오퍼 판정으로 연결한다. 서버 후보/임계치는 가정 입력이다. 상점은 내장Lv3 게이트다. 과거 체인은 관측6단계만 수령하며80젬 단계에서 정지한다. 카드팩 내용은 unknown으로 보관한다. 실제 IAP·광고·게임 서버 호출은 없다.

로컬 저장은 revision/schema/타입·수치·풀·타이머·로그/오퍼 구조를 검사한다. 손상 저장은 자동 삭제하지 않는다. 새 실험 전 이전 자료를 별도 키에 보관하며 JSON 내보내기/가져오기를 제공한다. 경과를 복원한 뒤 즉시 저장하여 중복 보상을 막는다. 최대7일은 웹 정책이고 현재 서버 규칙이 아니다. 같은 출처의 여러 탭 동시 편집/서버 동기화는 지원하지 않는다.
