## 자료와 재현 경계

- `apk-motion-evidence.json`: 원본22파일 출처·SHA·행 범위,8동작·3클립의 선정 곡선. 명시 시간과 미지정 easing을 구별한다.
- `apk-media-assets.json`: Area4/Timeline/Skin 정확 등록, CG binary·atlas·texture·분리 ani 연결 및 선정 파생. 원본 geometry/스켈레톤 전문/번들은 공개하지 않는다.
- `item-representation.json`: 기본8/전용35의 판정과 Bubble source 합성. 기본544 이미지 및 공용24 집계를 변경하지 않는다.
- `apk-media-review.json`:11고정항목,78시각 비교 자료(기존 관측 자료의 연결 포함),130미디어 항목. PNG/GIF poster를 포함한 새 공개 파일은140개다. 수량은 작업 완성률이 아니다.

8규칙GIF는20fps이며, source에 없는 위치·world→pixel 비율·미지정 easing·jump 궤적·공장 비행 Sin 함수는 웹 근사다. hint/idle 외의 시작 전 대기와 끝 정지는 설명용이며 원본 시간표와 구별한다. 상자 예시는 내부201의 노출이며 거미줄을 임의 추가하지 않는다. 공장 좌우 이동은 clip의 절대 anchoredX에서 초기값을 뺀 delta로 표시한다. source desc scale은 웹 문구에, alpha는 별도 합성한 배경에 적용한다.

CG 자료는 호환 Spine3.8.99 parser로 원본 bone/IK/deform/attachment/draw-order를 계산한320px CPU 파생이다. 원본 Unity runtime은 실행하지 않았다. 별도 `.ani.bytes`로 저장된 scene3_Quinn의3클립도 정확 이름과 끝까지 읽기 검사를 거쳐 포함했다. GIF의10ms 양자화·분석 샘플·독립 반복은 원작의 전이/loop 여부를 보장하지 않는다.

맵캐릭터44종 중15종의 정확 prefab/Spine을 확보했다. 원본410항목은 움직임409개와 Buster의0초/timeline0 초기 포즈1개다. 대표15표본은 움직이는 GIF14개와 정적 PNG1개이며395개 모션은 이름·기간·track 정보만 확인한 미시연 범위다. 별도 `.ani`292개는 정상 embedded animation과의 관계를 입증하지 않은 채 대체하지 않았다. 나머지29캐릭터의 등록 경로와 실물 부재를 같은4.10에 기록한다.

CDN 리터럴 도메인과 정확 bundle hash는 확보했으나 `AddressableManager.remoteLoadPathPrefix` 및 `remoteLoadFolder`의 실제 대입값이 검증되지 않았다. 주소를 임의 조합하거나 계정/서버 API에 접속하지 않았다.
